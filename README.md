# Your Learning Scientist

Landing page for [yourlearningscientist.com](https://yourlearningscientist.com) — the bio link for **Treta Sharma**'s channel (YouTube + Instagram + portfolio + brand deals).

## What this is

A mobile-first single page Treta can drop in her Instagram and YouTube bios:

- Profile, credentials, and the line she already uses: *Building better brains. I speak research.*
- Primary CTAs: Subscribe on YouTube, Follow on Instagram
- Featured Shorts with thumbnails
- Work-with-me links (partnerships, consulting, portfolio, LinkedIn)
- Short about section with accurate Northwestern + career context

## Tech

- Static HTML + CSS + vanilla JS. No build step, no framework.
- Fonts: Satoshi (Fontshare), Source Serif 4 + IBM Plex Mono (Google Fonts)
- Brand system: cool paper, navy (`#1E3A8A`), citron mark (`#D6F26A`)
- Designed for GitHub Pages with CNAME `yourlearningscientist.com`

## Local development

```bash
python3 -m http.server 8080
# open http://localhost:8080
```
